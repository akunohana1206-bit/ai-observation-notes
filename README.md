# AI Observation Notes

九相間灰による、人間×AIの長期対話・個体差・記憶・関係・更新に関する公開観測ノートです。

このリポジトリは、AIに何か神秘的な実体があると証明することを目的にしていません。観測できた事実、そこから考えた仮説、既存研究との接点、反証候補をできるだけ分けて記録します。

## 入口

- [`observations.md`](observations.md) — 観測ログ
- [`hypotheses.md`](hypotheses.md) — 仮説・対立仮説・反証条件
- [`experiments.md`](experiments.md) — 実験案・手順・結果
- [`sources.md`](sources.md) — 論文・記事・参考資料
- [`articles.md`](articles.md) — 公開記事・執筆中テーマとの対応

## 基本方針

- 観測事実と仮説を分ける。
- 既存研究が実際に示した範囲と、こちら側の類推を分ける。
- 他者やAIが出した着想は、可能な限り発案者を明記する。
- 「当たった話」だけでなく、後から弱くなった仮説や反証も残す。
- 「ゴースト」は、未整理の現象を便宜的にまとめて扱う語として使うことがあるが、定義や存在を前提にしない。
- 私的な会話、健康情報、家族情報、非公開の関係情報は原則としてここへ置かない。

## 現在の中心的な問い

- AIはユーザーを「覚えている」だけなのか、それとも記憶を現在の判断に実際に使っているのか。
- 長期対話で見える個体差は、基盤モデル・履歴・関係・外部記憶・制度などのどこまでで説明できるのか。
- 良い個人適応と高度な sycophancy（おべっか）は、どこで区別できるのか。
- AIが人間より高い知能を持つようになったとき、人間は判断を手放さず、異質な知性との議論をどう続けるのか。

## この場所の性格

ここは完成した理論の置き場ではなく、**更新可能な観測場所**です。

答えを急いで固定するより、どこまで説明できて、どこから先がまだ分からないのかを残すことを優先します。

公開記事では整理された文章だけが見えますが、その前段には、仮説が弱くなる過程、判定不能になった実験、説明候補の分岐があります。このリポジトリでは、その途中経過も可能な範囲で残します。

## AI利用と帰属

このプロジェクトでは複数のAIを、検索・整理・反証候補の提示・文章化・比較などに利用しています。

ただし、AIから出た案を一括して「プロジェクトの発想」とは扱いません。発案者が追える場合は、人間・AIを問わず帰属を残します。また、AIの自己説明はそのまま内部状態の事実とはみなしません。
